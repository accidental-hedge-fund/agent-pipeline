# v1.40.1 grill-with-docs review

Snapshot: 2026-09-01. Scope: every issue assigned to GitHub milestone `v1.40.1` during the review, including the replacement workflow issue created from the findings.

The review used the milestone dependency graph as the design tree. Repository and GitHub facts were gathered before decisions were settled. The operator authorized automatic acceptance of evidence-backed recommendations and required interruption only for choices that could not be inferred or required new protected authority. No such question remained after the factual review.

- Root contracts `#990`, `#993`, and `#1322` now define the dispatcher boundary, zero-cycle gate, universal lifecycle ownership, cancellation authority, and typed request boundary.
- Runtime chain `#1323`–`#1329` and `#992` now define the sole RecoverySupervisor, operation observations and invariants, recovery episodes, recommendation-first requests, compatibility projection, canonical numeric admission, stage-adapter boundary, and complete command-form disposition inventory.
- Integration and delivery chain `#1330`–`#1333` and `#1024` now define effectively-once merge, discriminated shipment intent, Candidate Lineage, host-neutral liveness, and the executable fault matrix.
- Evidence issues `#1301` and `#1368` now define live train linkage, collision-safe evidence identity, merge-proof disposition, Logical Operation correlation, and exact release SLO denominators.
- Exact-candidate issue `#1344` keeps its authenticated Decisions artifact and now states that candidate preparation failures remain supervised rather than becoming human ownership.
- Preflight issue `#1362` was stale against merged `#1364` / PR `#1365`. Its specification now preserves the explicit `supported: false` compatibility behavior and narrows the remaining work to genuine omitted, malformed, or otherwise typed preflight refusals.
- New issue `#1369` replaces the single-issue signed-envelope intake from `#1072` / PR `#1316` with a native grill-with-docs batch workflow, recommendation auto-acceptance, domain-document proposals, and automatic ready admission for issue, issue-list, milestone, and label selectors.

Every open milestone issue contains a `## Decisions` section and a `grill-with-docs:v1.40.1` review marker. Existing Pipeline Decisions artifacts were retained only where they remained coherent.
