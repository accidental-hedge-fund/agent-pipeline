# Grill-with-docs is a native Pipeline workflow

Pipeline recreates the design-tree interview and domain-document discipline as a native, versioned CLI workflow instead of invoking a personal host skill or host-specific Skill tool. The CLI remains the portable product while hosts stay thin wrappers; evidence-backed recommendations may be accepted automatically, but protected authority remains an authenticated typed boundary. Repository glossary and ADR changes use normal branches and pull requests rather than direct integration-branch writes.
